# Grade 12 Python Program

Welcome to the Grade 12 Python Program repository! This collection contains Python programs covering various fundamental programming concepts taught in Grade 12 Computer Science.

## 📚 Overview

This repository is organized into two main tasks, each containing multiple Python programs that demonstrate different programming concepts and techniques:

- **Task 1**: 15 programs covering loops, lists, tuples, and string operations
- **Task 2**: 15 programs focusing on functions, data structures, and advanced concepts

## 🎯 Topics Covered

- **Basic Input/Output**: Using `input()` and `print()` functions
- **Control Structures**: `if-else`, `for`, `while` loops
- **Data Types**: Integers, strings, lists, tuples, dictionaries
- **String Operations**: String manipulation, analysis, formatting
- **Lists and Tuples**: Creation, traversal, modification
- **Functions**: Definition, parameters, return values
- **Mathematical Operations**: Factorial, series calculations, geometric formulas
- **Date Formatting**: Converting date formats
- **Algorithms**: Fibonacci series, pattern generation

## 🚀 How to Run

1. **Prerequisites**: Make sure you have Python 3.x installed on your system
   ```bash
   python --version
   ```

2. **Clone the repository**:
   ```bash
   git clone https://github.com/Siva-Balan-V/Grade-12-Python-Program.git
   cd Grade-12-Python-Program
   ```

3. **Run any program**:
   ```bash
   python "Task 1  Program 1"
   ```
   or
   ```bash
   python "Task 2 Program 1"
   ```
